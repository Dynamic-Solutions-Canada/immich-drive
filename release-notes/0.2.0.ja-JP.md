- ImmichDrive が 9 つの言語に対応しました: 英語 (米国とカナダ)、スペイン語、フランス語 (フランスとカナダ)、ドイツ語、簡体字中国語、ポルトガル語 (ブラジル)、日本語。Windows の言語に従うほか、[設定] の [言語] で選ぶこともできます。
- 設定ウィンドウを一新しました。[ホーム] と [接続] のページ、[バージョン情報] ページ、[設定をリセット] があります。リセットではテーマ、言語、ウィンドウのサイズが戻り、ドライブの接続は切れません。
- サーバー アドレスが http:// で始まる場合、[接続] ページに警告が表示されます。API キーと写真が暗号化されずにネットワーク上を送信されるためです。
- Immich が API キーを拒否した場合、毎分再試行するのではなく、[再試行] を選ぶまで同期を一時停止します。
- アンインストール後にドライブのフォルダーを削除できるようになりました。ImmichDrive の実行中は、引き続き Upload フォルダー以外での変更を拒否します。
- サインイン時に起動しても、使用中のウィンドウからフォーカスを奪わなくなりました。また、終了時に数秒待つこともなくなりました。
- サムネイルのログに写真のパスを記録しなくなり、サイズを小さく抑え、アプリのデータ フォルダーに保存するようにしました。
- スクリーン リーダーがすべてのボタンを名前で読み上げるようになりました。
- 修正: 新しいドライブにフォルダー アイコンが再び表示され、[バージョン情報] ページの文字がダーク テーマでも読みやすくなりました。
- Windows 11、または 2024 年 10 月の更新プログラム (ビルド 19045.5011) 以降を適用した Windows 10 22H2 が必要です。
