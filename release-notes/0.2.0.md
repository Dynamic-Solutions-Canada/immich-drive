- ImmichDrive now speaks nine languages: English (United States and Canada), Spanish, French (France and Canada), German, Simplified Chinese, Brazilian Portuguese and Japanese. It follows Windows, or you can pick one under Settings, Language.
- A redesigned settings window, with Home and Connection pages, an About page and Reset settings, which resets the theme, language and window size without disconnecting your drive.
- The Connection page warns when your server address starts with http://, because your API key and photos would cross the network unencrypted.
- When Immich rejects your API key, sync pauses until you choose Try again, instead of retrying every minute.
- Uninstalling now leaves a drive folder you can delete. While ImmichDrive runs, the drive still refuses changes outside the Upload folder.
- Starting at sign-in no longer takes focus from the window you're using, and exiting no longer waits several seconds.
- The thumbnail log no longer records photo paths, stays small, and is kept in the app's data folder.
- Screen readers now announce every button by name.
- Fixed: a new drive shows its folder icon again, and text on the About page is readable in the dark theme.
- Requires Windows 11, or Windows 10 22H2 with the October 2024 update (build 19045.5011) or later.
