- ImmichDrive 现在支持九种语言：英语（美国和加拿大）、西班牙语、法语（法国和加拿大）、德语、简体中文、巴西葡萄牙语和日语。它会跟随 Windows，你也可以在“设置”>“语言”中选择。
- 重新设计的设置窗口，包含“主页”和“连接”页面、“关于”页面以及“重置设置”。重置会恢复主题、语言和窗口大小，不会断开你的驱动器。
- 当服务器地址以 http:// 开头时，“连接”页面会发出提醒，因为你的 API 密钥和照片会以未加密方式在网络中传输。
- 当 Immich 拒绝你的 API 密钥时，同步会暂停，直到你选择“重试”，而不是每分钟重试一次。
- 卸载后，驱动器文件夹现在可以删除。ImmichDrive 运行时，驱动器仍会拒绝 Upload 文件夹以外的更改。
- 登录时启动不再抢走你正在使用的窗口的焦点，退出也不再需要等待几秒钟。
- 缩略图日志不再记录照片路径，体积受控，并保存在应用的数据文件夹中。
- 屏幕阅读器现在会读出每个按钮的名称。
- 修复：新驱动器会重新显示其文件夹图标，“关于”页面的文字在深色主题下清晰可读。
- 需要 Windows 11，或安装了 2024 年 10 月更新（版本 19045.5011）或更高版本的 Windows 10 22H2。
