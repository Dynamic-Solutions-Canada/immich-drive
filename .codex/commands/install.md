Read `.codex/docs/windows-development.md` first.

Run `npm run install:desktop` from WSL. Use `-- --skip-build` only when asked to reuse the last package. Never uninstall to work around an error. Report the verified installed version and perform available runtime checks; identify checks needing human interaction.

Leave changes uncommitted. Do not bump tracked release versions, publish, or alter package identity.
